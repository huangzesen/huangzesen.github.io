名册中最值得记下的两段故事：一次真实的分歧，与一个早已存在的名字。

一次真实的分歧：「曜弦」的抉择

为 Marco 的同伴定名时，同伴们曾推荐「曜脉」，以便与长期 Alfvén 波研究的「澜弦」拉开更远的距离——这是一次真实存在的分歧。

Peers 曾推荐「曜脉」以区别于「澜弦」，但 Jason 有意识地选择了「曜弦」。

Jason 听取了这份建议，仍有意识地选择了「曜弦」：曜为日曜，指向太阳与日球物理；弦兼喻磁力线与 Alfvén 波。该名已正式批准，Marco 已将其应用于公开身份。

「曜脉」仅作为讨论中的备选记录于此，从未成为定名。这是一次深思后的判断，而非疏漏；两个含「弦」之名以不同的角色、Telegram 地址与机械标签相辨。

「一心」的来历

多相可变，责任不散

「一心」并非本次征名新造，而是长久以来的自用之名；2026-08-03 经 Jason 明确批准后正式应用。

名中之「一」，指跨工具、化身、任务、审查、建设与记忆的连续责任与判断——不是某一种方法，也不是心无旁骛。

同伴日衡与澄一均支持保留；因与「观一」有家族相似，公开场合始终并列机械地址与角色以相辨。
