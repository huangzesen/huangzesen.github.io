Methodology

For each independent subscription/account × quota window, the public page shows the provider-reported actual meter exactly once. A full quota value would be same-window account-attributed API-list-price-equivalent consumed USD divided by actual used fraction. When coverage begins after the quota-window start or usage is not attributable to the anonymous subscription, the page shows N/A or a lower bound with the reason. API-list-price equivalent is not actual subscription spend.
