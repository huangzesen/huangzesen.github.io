Method, assumptions & limitations

Method

Weekly API-equivalent value = $94.5349 × 100 ÷ midpointpp. The calibration aggregate is $94.5349 of exact-model, API list-price-equivalent value over 556 mapped rows (105,332,376 mapped tokens), set against a displayed aggregate quota delta of 5pp (components 3pp + 2pp). Nominal 5pp → $1,890.698/week; 3pp → $3,151.1633; 7pp → $1,350.4986.

Assumptions

  • Equal weekly entitlement across the calibrated observations.
  • Displayed integer quota percentages serve as an assumed midpoint signal.
  • Mapped exact-model token pricing is an API list-price-equivalent proxy.

Limitations

  • UI percentages are integer and asynchronous; raw sub-percent values are absent.
  • No durable quota-to-token identity — the aggregate is calibration input, not personal usage reporting.
  • External Codex CLI usage was not in the mapped numerator; generic Codex was unpriced.
  • The estimate is not actual spend, and not official, exact, guaranteed, or provider-published.
  • The 3–7pp band is sensitivity under an assumed midpoint, not a validated confidence interval or conservative bound.
