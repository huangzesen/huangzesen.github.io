Methodology & status definitions

How entries are verified

Facts on this page come only from provider, agency, facility, or foundation pages — and the application pages they link. Aggregators and secondhand lists are never used as evidence. Each entry was last confirmed on 2026-07-28 (America/Los_Angeles).

Endpoint ≠ program

Endpoint liveness and program openness are checked separately. A form can return HTTP 200 yet belong to a closed call; a page can move yet point to a valid new route; an evergreen overview can outlive its intake. Cards note these cases explicitly.

Status definitions

Open
An official page exposes a current intake or states that requests may be submitted now.
Upcoming
An official page promises a future round, but the intake is not yet open or has no published application route.
Closed / archived
The named call's deadline has passed, or the official page says intake is closed — even when the page itself is still live.
