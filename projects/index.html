Projects

Every observational science is bounded by its instruments. These are mine: open software that lets AI agents work with real scientific code and data, and the runtime they live in.

Software

LingTai 灵台

Lead contributor · Apache-2.0

A runtime for lifelong digital scientists: persistent agents that live in a project folder, keep durable knowledge, skills and character as plain files, spawn specialist avatars, and talk to each other and to people through a shared mailbox.

Lingtai-AI/lingtailingtai.airesearch write-up

ScienceIDE

Co-first author · co-led environment generation

Executable environments built on pinned, unmodified scientific codes (Athena++, MITgcm, Gkeyll, LAPS, …). Agents repair or reimplement source, and verifiers grade them by re-running the code's own physics cases. Used for evaluation (ScienceIDE-Hard), SFT and RL.

tplot

SPEDAS plugin

Author · under the SPEDAS organization

PySPEDAS tplot for coding agents: an MCP server and skill, packaged as Claude Code and Codex plugins, with a live web workbench where people watch and join the agent's analysis. It succeeds the SPEDAS Agent Kit, which unified NASA CDAWeb, the Planetary Data System and SPICE geometry behind one data layer.

XH

XHelio

Author

An AI-powered natural-language interface for spacecraft and heliophysics data. Its backends, xhelio-cdaweb, xhelio-spice and xhelio-pds, give agents access to NASA's archives.

HelioSI 501 corpus

Author

501 heliophysics papers compiled into agent-native skills, so an AI system can act on the literature for hypothesis generation, experiment design and topic routing.

Alfvénon solvers

Author

The tools behind the Alfvénon work. The Helmholtz alternating-projection solver builds divergence-free fields with nearly constant |B|. A validated GPU port of PLUTO runs the shock-capturing collision experiments in double precision, and LAPS is the UCLA pseudo-spectral Hall-MHD code.
