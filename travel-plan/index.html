Eastern Sierra · Expedition Dossier · Mammoth Lakes Base

东部山脉·六日

2026年8月3日(周一)→ 8月8日(周六) · Mammoth Lakes base · Big Pine

高海拔花岗岩湖盆 · 干燥强日照 · 午后雷暴窗口 · 一条施工管制的山谷公路——这是一份把「能放弃什么」写得和「想去哪里」一样清楚的行程档案。

结论先行

最安全、最可执行的顺序:周一(8/3)从 Berkeley 转移到 Mammoth Lakes base;周二(8/4)用 Rush Creek Trailhead 做 Thousand Island Lake 的高强度尝试;周三(8/5)从 Coldwater Campground 走 Duck Pass 方向,保守成功线是 Barney Lake;周四(8/6)按既定的 Devils Postpile 强制班车方案;周五(8/7)清晨退房,南下 North Fork Big Pine Creek,以 First/Second/Third Lake 中能按时安全完成者为目标,夜宿 Big Pine;周六(8/8)离开。

强制降级原则:Rush Creek→Thousand Island Lake 与 Big Pine Lakes 都是 very strenuous 的可选目标,不是必达清单。任何一天都可以缩短或取消——睡眠、步速、烟霾、雷暴、积雪/溪流与道路状态,永远优先于「打卡」。

本页编制于 2026-07-28,是一份定稿日期明确的计划文档,不是实时路况或天气保证;执行前按「72 小时 / 24 小时 / 当日清晨」节奏复核文末官方入口。

08·04Tue · 周二

千岛湖:Rush Creek 入口的高强度尝试

Thousand Island Lake via Rush Creek Trailhead · Ansel Adams Wilderness
Very Strenuous · 可选18–20+ mi 往返(估算)回退:Gem / Agnew Lake硬门槛11:00–11:30湖边硬返

为什么走这里

  • Reds Meadow Road 施工季周一至周三对所有交通(含行人、自行车、e-bike)关闭——Agnew Meadows / High Trail / River Trail / Shadow Creek 等入口周二全部不可用。
  • Rush Creek 是合法但极端的替代入口:自 US-395 转 CA-158,至 Silver Lake 北端右转入 Rush Creek Trailhead 停车场;USFS 说明该入口通往 Agnew Lake、Gem Lake、Waugh Lake 与 John Muir Trail。
  • 沿 Rush Creek 上行经 Agnew Lake、Gem Lake,向 Waugh Lake/JMT 方向,按离线 topo 与现场标志朝 Thousand Island Lake / Island Pass 方向推进——仅在路线明确且时间充裕时继续。
  • USFS 未发布本线完整里程表;18–20+ mi、爬升 3,000–3,900 ft、高点 10,000–10,225 ft 均为路线网站保守规划值。现场停车位、标牌与临时限制以当日为准。

时间门

  • 03:45到车。头灯出发,夜段走稳不走快。
  • 04:00起步。
  • 06:30Agnew/Gem 体能门:步速或状态不稳,就把今天定格为 Gem/Agnew 往返。
  • 09:00若尚未接近上段/JMT 方向,立即回撤。硬门槛09:00
  • 11:00–11:30Thousand Island Lake 硬返——不因「差一点」延长。硬门槛11:00–11:30
  • 18:30仍未回到 trailhead 即视为失败,疲劳风险显著上升。

GO / NO-GO

GO 全部满足才成立前晚睡眠足 · 无明显高反 · NWS 雷暴风险低 · 烟霾可接受 · CA-158 可通 · 现场无临时封闭 · 全队接受 10–12 小时 strenuous day。
NO-GO / 降级任一不满足 → Gem Lake / Agnew Lake 往返(仍是高海拔 strenuous,但有恢复余地)。任何雷声都触发立即下撤,避开高地与水边。

许可与规则

  • Day use 不需许可;Ansel Adams Wilderness 仅荒野过夜需 permit(Rush Creek 配额 5/1–11/1 为 30 人/日)。本计划城镇过夜,不提交许可。
  • 食物、垃圾与有气味物品使用 bear-proof 容器;狗按 Inyo NF 规则控制,trailhead 与开发区系绳。
  • Trailhead 有旱厕;水龙头供水在官方页面间表述冲突——按「自带满水 + 天然水过滤/消毒」执行,不依赖龙头。

风险画像

  • 起点约 7,000 ft 级、路线至约 10,000 ft 级:热晒、暴露、午后雷暴、烟霾、残雪/湿滑石面、溪流与迷路都可能出现。
  • 头痛伴恶心、眩晕、异常疲劳、协调变差或静息呼吸困难 → 下撤并求助,不「硬适应」。
  • 手机无信号不能当救援计划;离线地图与回撤时间表才是。

本日检查与来源

72h/24h/当日清晨:Inyo alerts、CA-158、NWS 点预报、AirNow 烟霾,并向当地 visitor/ranger 询问残雪、溪流与临时封闭。

08·05Wed · 周三

湖盆日:Duck Pass 方向,以 Barney Lake 为保守成功线

Duck Lake / Duck Pass via Coldwater Campground · Mammoth Lakes Basin
高强度 · 可降级首选回退:Barney Lake硬门槛12:00Duck Lake 硬返

入口与路线

  • 自 Mammoth Lakes 走 CA-203 / Lake Mary Road,经 Lake Mary 按标志抵 Coldwater Campground;Duck Pass Trail 从营地后方起步。
  • 序列:Coldwater → Arrowhead Lake → Skelton Lake → Barney Lake → Duck Pass → Duck Lake,原路返回。
  • 官方确认线路与目的地但未给完整里程表:垭口观景点约 7.2 mi 往返、爬升约 1,680 ft、高点约 10,800 ft;Duck Lake 全程约 10–11+ mi,爬升在各资料间冲突——一律按 strenuous 规划,不采信单一「精确值」。
  • Lakes Basin trolley 时刻不可靠且可能需步行接驳:以合法自驾到 Coldwater、现场停车为主,不把 trolley 当保底接送。

时间门

  • 05:45起床。
  • 06:15到车;用 Coldwater 开放设施(状态当日确认)、装水。
  • 06:45–07:15起步。
  • 09:00–09:30Barney 体能/天气门:不合格即以 Barney Lake 收官。
  • 10:30–11:00Duck Pass。垭口积雪超出装备/技能 → 回头。
  • 12:00从 Duck Lake 硬返,不再逗留。硬门槛12:00
  • 16:30–17:00收线目标;14:00 应已回到垭口下方。

GO / NO-GO 与回退阶梯

GO 条件Barney 处仍有稳定步速 · 无雷暴/强风 · 无超出能力的残雪。
NO-GO雷声、垭口危险积雪、或回程将晚于时间门 → 立即执行回退。
  • Duck Lake——全值目标,仅当各门全过。
  • Duck Pass 观景点——次级目标(≈7.2 mi 往返,估算)。
  • Barney Lake——首选成功线:较短、低风险,足以称为完整的一天。
  • Skelton / Arrowhead——更早回头同样合法。

规则与设施

  • Day use 免许可;荒野过夜才需 permit(配额 30 人/日),本计划不露营、不提交。
  • Coldwater Canyon / Duck Creek / Purple Lake 一带禁营火,10,000 ft 以上全域禁营火;bear-proof 容器;距 Duck Lake / Purple Lake 出水口 300 ft 内不得扎营;队伍 ≤15 人。
  • 天然水必须过滤/消毒;带足午餐与水,不预设沿途补水。
  • 狗按 Inyo NF 规则;未查到该入口独立 day-use fee——以现场牌示为准,不预设免费。

本日检查与来源

72h/24h/当日清晨:Inyo alerts、NWS、AirNow、本地步道状态与停车/设施公告。午后雷暴、日晒、烟霾、残雪/冰与溪流是主要变量。

08·06Thu · 周四

魔鬼柱:全周唯一的山谷窗口,按既定班车方案执行

Devils Postpile National Monument → Rainbow Falls · mandatory ESTA shuttle
恢复 / 中等日道路仅周四 07:00 起开放施工延误 ≤2.5h硬门槛15:30完成返程排队

山谷硬规则 · 全周行程围绕它排布

周四 07:00 → 周日 23:00

2026-07-06 至 09-02,Reds Meadow Road 每周只在此窗口开放;周一至周三对所有交通关闭——机动车、行人、自行车、e-bike 一律包含。07:00 前进入不被授权。

延误最长 2.5 小时

周四 07:00–20:00 施工放行可能造成最长 2.5 小时交通延误。这是「可能的上限」,不是可预测的排队模型——必须用实际到谷时间现场决策。

ESTA 班车强制

道路开放期间 07:00–19:00 强制乘坐 ESTA 班车,上车点 Mammoth Mountain Main Lodge。Mammoth Lakes base 不属于山谷内住宿豁免——不能自驾进谷。

$15 · $7 · 免费

成人 $15;3–17 岁 $7;2 岁以下免费;官方强烈建议提前预约。周四自 Main Lodge 07:30–19:00 每两小时一班;山谷末班返程 19:00。宠物乘车需牵绳并戴口笼。

时间门

  • 06:15起床、早餐,灌满每人 ≥2 升水,装打包午餐——resort 餐饮不当作保证。
  • 06:50离开 Mammoth Lakes base 前往 Main Lodge。
  • 07:05–07:20停车、厕所、票/预约核对、排队。
  • 07:30目标首班班车;此后每两小时一班,错过一班代价很大。
  • 入谷后先到 Devils Postpile 站/护林员站核实步道与班次,看柱体;再按官方 moderate 路线走向 Rainbow Falls(官方地图注记约 3.8 mi 至瀑布班车站),自 stop 9(Rainbow Falls Trailhead)或 stop 10(Reds Meadow Resort)返乘。以路线图与现场指示为准,非精密 GPS 承诺。
  • 15:30开始排返程队——绝不把 19:00 末班车当计划的一部分,那是应急余量。硬门槛15:30

回退与检查

道路/班车未确认开放 = NO-GO当日早晨若道路或班车未被官方确认运行,整日切换为当日已确认可达的 Mammoth Lakes Basin / 镇内活动,不再尝试进谷。
  • 72h(8/3):查 NPS conditions、USFS 施工公告、NWS、AirNow。
  • 24h(8/5)与当日清晨:复核道路开放、班次、延误、空气与雷暴。

08·07Fri · 周五

南下 Big Pine:湖到哪一级,由状态说了算

North Fork Big Pine Creek · First / Second / Third Lake · Big Pine overnight
Very Strenuous · 可选First/Second 即成功连续行程末尾 · 疲劳敏感硬门槛12:15不再上推

转移与入口

  • 04:45起床;清晨从 Mammoth Lakes base 退房装车。
  • 05:00出发:CA-203 → US-395 South,经 Bishop 到 Big Pine;西转 Crocker Ave 接 Glacier Lodge Road 约 10 mi 到路尽头。车程规划 1h35–1h50 加停车缓冲——规划估计,非实时保证。
  • 06:25–06:40停 day-use parking(Glacier Lodge 附近路尽头);不得占用下方 overnight/backpacker 停车场。厕所、装水。
  • 06:45起步进入 North Fork,经 First Falls / Second Falls 方向上行。

时间门

  • 10:15–10:45First Lake 门:状态一般就在此收官——这已是完整成功。
  • 11:30–12:15Second/Third 决策窗:只有步速、天气、体力全好才考虑 Third。
  • 12:15硬返——此后不再向上推进,不追 Black Lake / Fourth Lake / Glacier 方向。硬门槛12:15
  • 14:00必须离开高湖盆地。
  • 16:30–18:00回到车上;随后 Big Pine 过夜。

路线量级(估算)

  • First Lake ≈9–10 mi 往返 · 爬升 ≈2,100–2,300 ft——保守目标,足够成功。
  • Second Lake ≈10–11 mi · ≈2,250–2,500 ft——常规目标。
  • Third Lake ≈11–13+ mi · ≈2,600–2,700 ft 级——仅条件全好时的全值目标,默认不是承诺。

湖群海拔约 10,000 ft 级;数字为第三方路线估算,随起点/停车点与 GPS 口径浮动,USFS 未发布逐湖里程表。

GO / NO-GO

降级即胜利前两日已有累积疲劳 → First/Second Lake 就是今天的成功定义。
